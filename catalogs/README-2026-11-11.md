## Verification

[Verify November 2026 game source scout](../.github/workflows/verify-nov-2026-scout.yml)
uses the authenticated GitHub GraphQL repository API in batches. The
script `scripts/verify-nov-2026-scout.py`:

1. Confirms public, nonempty GitHub repository identity and obtains its
   canonical URL.
2. Compares canonical identity with all prior 2,418 URL identities and
   known Gitea destination names.
3. Suppresses duplicate canonical identities, redirects to previously
   mirrored URLs and naming collisions, placing them in review reports.
4. Flags empty, deleted/private/inaccessible, disabled and ambiguous
   responses without incorrectly treating rate limits or API outages as
   repository deletions.
5. Marks very small/low-signal repos and small redundant forks as
   **track only**, not as confirmed junk.
6. Emits Gitea Mirror repository-list JSON v1 and audit metadata only after
   every GitHub API batch completes.

Importing a new list doesn't delete, move, retarget, or repair repositories
already tracked by the companion. Continue to manage failed existing mirrors
separately.

### What this scout cannot prove

A public nonempty repository may still be a placeholder, broken project,
unofficial fork, incomplete decompilation, or a native compatibility layer
rather than a source-code reconstruction. Labels such as `static-recomp`
come from the community catalogs and are not independently proved by a
compiled build. Repository availability can change at any time.

The repo lists are source-code links only. They do not contain ROMs, ISOs,
game assets or commercial binaries.
